Only **[Minecraft](https://www.minecraft.net/en-us) mods** are supported.

Supported **mod loaders**:
- [Fabric](https://fabricmc.net/)
- [Forge](https://files.minecraftforge.net/net/minecraftforge/forge/)
- [NeoForge](https://neoforged.net/)
- [Quilt](https://quiltmc.org/en/)

Supported **mod pack formats**:
- [.mrpack (Modrinth)](https://support.modrinth.com/en/articles/8802351-modrinth-modpack-format-mrpack)

*This project is not affiliated with any of the mentioned services.*
