This website refers to `luludodo.de`.

This article specifically refers to data in the context of the 
[`Web Storage API`](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API).

# When will data be stored?

This website will only start locally storing data after you have consented. 
By consenting once, you give permission to storage data,
until you retract your consent. (This can be achieved by clicking on the "Show Popup" button above and selecting "No")

Although there is an **exception**: This website will store the options selected in the popup, even if you select "No".

# What data will be stored?

The data being stored is usually a copy of files you edited/opened. 
It can also include an edit history.
Only data directly uploaded to this site will be stored.

# Why is data stored?

In order to prevent accidentally losing progress when refreshing the page or restarting your computer.

The selected option is stored, in order to determine, if the user has consented to storing more data.

# Where is the data stored?

Data is stored on **your** computer,
more specifically as 
[local](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) or 
[session](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage) storage.

It has **not** and will **never** be uploaded to the cloud (without your explicit consent).

# Who can access my data?

Since the data is only stored on **your computer**,
only people with access to the drive used by your browser can access your data.
